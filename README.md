# Piece Mates – AI-Powered Team Building

An AI-powered team-building application developed during a hackathon by Team Trust Me Bro.

Piece Mates aims to help remote employees connect through an interactive treasure hunt experience, making online team-building activities more engaging and accessible.

## Key Features
- Interactive multiplayer treasure hunt
- AI-generated game content
- Personalized player avatars
- Collaborative challenges
- AI-generated visual content
- Remote team-building experience

## Technologies
- Artificial Intelligence
- Web Development
- Generative AI

## How It Works
Participants join a shared game session and create personalized avatars.

Players collaborate to complete challenges and discover hidden elements throughout the game.

The experience is designed to encourage communication, cooperation, and interaction between remote team members.

## Project Overview
The project was developed as a hackathon solution addressing the challenges of social isolation and limited interaction among remote employees.

It combines gamification, artificial intelligence, and collaborative gameplay to create an alternative to traditional online team-building activities.
